# 5세대 드림월드 추가 기능 실험본 사용법

2026-10-20 웹 점검 및 수정 내역: [점검 결과와 남은 한계](audit_reports/점검결과-2026-10-20.md).
일반 브라우저에서는 `http://127.0.0.1:8080/local/`에서 입장 안내·현재 상태를 확인하고,
`http://127.0.0.1:8080/local/customize`에서 설치된 스킨·도감·뮤지컬을 전송 예약할 수 있습니다.
원본 드림월드 게임 화면 자체는 여전히 Flash 실행 환경이 필요합니다.

이 폴더는 `dreamworld-reawakened` 최신 소스와 필수 하위 모듈을 포함합니다. PDW(포켓몬 드림월드)의 꿈섬, 미니게임 보상, 텃밭, 아이템 상자, 잠재우기/깨우기 흐름이 구현되어 있습니다.

폴더 이름에는 미완성이라고 표시되어 있지만 업스트림 기준본에 없는 기능을 추가로 구현·시험하는 비교본입니다. 안정적인 기준 동작을 먼저 확인하려면 `..\드림월드`를 사용합니다.

## 가장 간단한 실행

1. PC와 DS/3DS를 같은 네트워크에 연결합니다.
2. 이 폴더에서 PowerShell을 열고 다음을 실행합니다.

   ```powershell
   .\start-server.ps1
   ```

3. 화면에 표시되는 `Configure your DS to use the following DNS server:` 뒤의 IP를 DS/3DS 인터넷 설정의 **기본 DNS**로 입력합니다. 보조 DNS는 `0.0.0.0`으로 둡니다.
4. 5세대 게임의 타이틀 화면에서 게임싱크 설정으로 ID를 만들고, C기어 → 온라인 → 게임싱크에서 포켓몬을 재웁니다.
5. 최초 실행이라면 런처가 이를 감지해 웹 서버를 자동으로 시작합니다. `http://127.0.0.1:8080/`을 Flash가 동작하는 브라우저에서 엽니다.
6. 드림월드에서 놀고 난 뒤 반드시 사이트의 종료 절차를 완료한 후 게임에서 포켓몬을 깨웁니다.

종료는 실행한 PowerShell 창에서 `Ctrl+C`를 누르면 됩니다. 런처가 두 서버를 함께 종료합니다.

## 브라우저

원본 SWF는 NPAPI Flash에 의존하므로 Chrome/Edge와 Ruffle에서는 정상 동작하지 않습니다. 원본 프로젝트가 안내하는 조합은 Basilisk와 Flash Player 32.0.0.371입니다. Flash는 지원 종료된 소프트웨어이므로 이 로컬 서버 외 사이트 탐색에는 사용하지 말고, 별도 브라우저 프로필 또는 격리된 환경을 권장합니다.

대안으로 독립 실행형 Flash Player에서 다음 SWF를 직접 열 수 있습니다.

```text
http://127.0.0.1:8080/DreamWorld_data/src/swf/theme/assets/common/main.swf
```

## 문제 해결

- 실행 전 검사만 하기: `.\.venv\Scripts\python.exe .\doctor.py`
- `Port available` 실패: 표시된 포트를 쓰는 다른 DNS/웹 서버, VPN 또는 보안 프로그램을 종료한 뒤 재시도합니다.
- 웹 서버가 바로 안 뜸: 정상입니다. 먼저 게임싱크 ID를 만들고 포켓몬을 재워야 합니다.
- DS/3DS가 연결되지 않음: PC와 기기가 같은 네트워크인지, DNS가 실행창의 IP인지, Windows 방화벽에서 Python의 개인 네트워크 통신이 허용됐는지 확인합니다.
- 저장 데이터 위치: `save_data/` (Git에는 포함되지 않음)
- 웹 서버만 실행: `.\start-server.ps1 --web-only`
- 게임싱크 서버만 실행: `.\start-server.ps1 --game-sync-only`

## 현재 구현 범위

동작하는 주요 PDW 기능은 로그인/세션, 잠든 포켓몬 표시, 꿈섬 조우, 지원되는 미니게임 결과와 보상, 아이템 획득, 텃밭 파종·물주기·수확, 엔트리링크로 보낼 아이템 예약입니다. 이 보완판에는 다음 흐름도 추가했습니다.

- 미니게임에서 만난 포켓몬을 소원나무에서 열매와 교환해 친구보드에 등록
- 친구보드에서 최대 10마리를 선택하고 게임싱크의 Entralink 전송 데이터로 저장
- 선택 포켓몬의 특성·특별한 기술·성별·폼·등장 애니메이션 직렬화
- 나눔선반 전시, 회수, 교환과 영구 저장
- 드림 카탈로그 목록, 열매 구매, 보유 가구 및 방 배치 영구 저장
- 누락된 카탈로그 썸네일 SWF를 동일 가구의 본 이미지로 안전하게 대체
- DS가 다시 업로드되어도 웹의 친구보드·선반·가구 상태가 지워지지 않도록 병합 저장

자동 검증은 다음 명령으로 실행할 수 있습니다.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## 남은 원본 자료 의존 항목

포켓몬 비스트로(게임 5)는 카페의 숲 전용인데, 현재 배포 자료에는 카페의 숲 맵 `template50.swf`가 없습니다. 촛불 끄기(게임 6)는 SWF 조각은 있으나 어느 이벤트/포켓몬에서 호출됐는지에 관한 원본 캠페인 메타데이터가 없습니다. 서버는 두 게임이 완료 데이터를 보내면 공통 `game_clear` 보상·친구보드 흐름을 처리하지만, 현재 자료만으로 원본과 동일한 진입 경로를 복원하는 것은 보류했습니다. 해당 맵 SWF나 당시 네트워크 응답 캡처가 있으면 추가할 수 있습니다.
