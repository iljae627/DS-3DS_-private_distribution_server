# 드림월드 웹사이트 점검 결과 (2026-10-20)

## 확인 결과와 이용 방법

`드림월드-미완성부분구현`만 수정했습니다. 원본 `드림월드`와 실제 ROM 세이브 파일은 수정하지 않았습니다. 자동 기능 검증은 임시 데이터베이스에서 실행했습니다.

- 이용 안내: http://127.0.0.1:8080/local/
- 원본 게임: http://127.0.0.1:8080/pdw/ (Flash 실행 환경 필요)
- 스킨·도감·뮤지컬 전송 예약: http://127.0.0.1:8080/local/customize
- 실행: 이 폴더에서 `.\start-server.ps1`. 실행창을 유지하고 게임싱크에서 포켓몬을 재운 뒤 입장합니다.

## 수정한 오류

| 영역 | 확인한 원인과 조치 |
|---|---|
| 페이지·정적 파일 | 옛 공식 도메인 및 아카이브 경로를 로컬 주소로 변환. 경로 탐색을 차단하고, 누락된 언어 리소스는 실제 보관된 다른 언어 파일로 연결 |
| 빈 화면 | Flash 미지원 브라우저에는 입장 방법과 상태 확인 링크 표시. 계정 미등록 시 안내 화면 제공 |
| 카탈로그·나눔선반 | 실제 Flash가 POST로 읽는 요청을 서버가 GET 전용으로 처리하던 501 오류 수정. 선반·카탈로그 아이콘 원본 SWF 복구 |
| 방 배치·집 | Flash의 `interior[0]` 배열 형식 처리. 집 외관을 방 가구로 잘못 취급하던 분류 수정. 집 변경 저장. 신규 집 실내는 기본 실내로 대체 |
| 구매·아이템 | 열매 인덱스가 아닌 실제 아이템 ID로 계산. 수량·재고 검증과 전송 예약 취소 반환. 잘못된 예약으로 일부 재고만 차감되지 않도록 선검증 |
| 꿈섬·미니게임 | 실제 SWF의 결과 해시 검증, 실패 보상 방지, 중복 지급 방지. 이벤트 ID와 결과를 DB에 보존해 서버 재시작 후에도 처리 |
| 텃밭 | 접속 중 성장 재계산, 이른 수확·겹쳐 심기 차단. 텃밭 확장 시 기존 작물이 지워지던 오류 수정 |
| 게임싱크·프로필 | 잠든 포켓몬 정보를 DB에서 다시 조회. 깨운 뒤 세션 데이터 정리. 아바타 저장의 빈 응답 500과 일부 언어 조회 오류 수정 |
| 커스터마이즈 | 실제 설치된 DLC 목록과 전송 예약을 연결. 동작하지 않던 메뉴를 로컬 선택 폼으로 연결하고 파일명 검증 |
| 오류 응답 | Flash가 해석할 수 있는 구조로 오류 반환. 미지원 API를 성공한 것처럼 빈 객체로 숨기지 않도록 변경 |

## 자료 복구와 출처

누락 자료 27개를 공개 복원 저장소의 실제 파일로 복구했습니다. SHA-256, 출처 커밋, 경로는 [recovered-assets.json](recovered-assets.json)에 기록했습니다. 원본 자료의 권리는 원 권리자에게 있습니다.

- [기반 프로젝트 dreamworld-reawakened](https://github.com/minibug1021/dreamworld-reawakened): 실행 환경 및 알려진 미구현 영역 비교.
- [Dream-World-Revival](https://github.com/Shade-of-Gr3y/Dream-World-Revival): 선반 SWF, 카탈로그 아이콘 및 지원 페이지 리소스 복구.
- [dream-world](https://github.com/maxxu123456/dream-world): 카탈로그·종료·커스터마이즈 관련 알려진 문제 비교.
- [dream-server](https://github.com/NDSLink/dream-server): 드림월드 복원 자료 비교.
- 로컬에 보관된 원본 SWF의 ActionScript를 분석해 요청 메서드, 배열 인코딩, 결과 해시를 서버 구현과 대조했습니다.

## 자동 검증

`audit_reports/site-audit.json` 기준:

- 한국어 HTML 페이지 37개, API 29개, HTML/CSS 연결 리소스 659개 확인.
- 위 범위의 누락 리소스 및 API 실패 0개.
- 구하지 못한 도움말 그림 13개는 명시적인 안내 문구로 교체. 장식용 배경 4개는 요청하지 않도록 처리했습니다. 원본 그림을 복구했다는 의미가 아닙니다.
- 외부 링크 199개는 수집만 했으며, 옛 외부 서비스의 생존 여부나 기능을 보장하지 않습니다.
- `python -m unittest discover -s tests -v`: 7개 통과. 실제 Flash 요청 형식, 오류 구조, 보상 중복·재시작, 재고·작물 보존, DLC 예약 및 기존 친구보드·하일링크 직렬화 회귀 검증 포함.
- 재검사: `.\.venv\Scripts\python.exe tools\audit_site.py` 및 `.\.venv\Scripts\python.exe -m unittest discover -s tests -v`.

## 남은 한계

위 수치는 HTTP·서버 로직 검증이며, 모든 SWF 화면을 실제 클릭해 검증했다는 뜻은 아닙니다. 브라우저 자동 조작은 Windows에서 현재 URL을 신뢰성 있게 확인할 수 없다는 안전 제한으로 중단되었습니다. 이번 실행 환경에서 Basilisk/Flash 화면 전체 조작 및 DS 실기 수령은 검증하지 못했습니다.

일반 가구 전체 카탈로그, 집별 고유 실내, 카페의 숲 `template50.swf`, 비스트로·촛불 끄기의 원본 진입 메타데이터는 아직 부족합니다. 기본 집 가격은 로컬 기본값이며 역사적 원본 가격 복원은 아닙니다. 타 이용자와의 실제 교류, 공식 대회·캠페인·회원가입은 제공하지 않습니다. 가짜 친구·방문자 목록은 빈 목록으로 바꾸고 아카이브 화면에는 안내를 표시했습니다.

원본 Flash는 지원 종료된 환경입니다. 별도 환경에서 로컬 서버에만 사용하고 외부 웹 탐색에는 사용하지 마세요.
