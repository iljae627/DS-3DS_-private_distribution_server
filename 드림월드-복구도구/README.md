# 드림월드 두 폴더 복구·검사

루트의 `드림월드`는 기준본, `드림월드-미완성부분구현`은 추가 구현본입니다. 밑줄 이름의 중복 폴더는 만들지 않았습니다.

## 이번 확인 결과

2026-11-05, 두 폴더 모두 공개 원본이 요구하는 코드 125개·자료 10,464개·게임싱크 코드 97개가 존재했습니다. 삭제된 파일은 확인되지 않았습니다. 두 폴더의 원본 이미지·SWF는 공개 원본의 Git 객체 해시와 일치했습니다. 기존 텍스트 수정본은 덮어쓰지 않았습니다.

`restoration.json`은 존재 여부와 복구 내역, `integrity.json`은 해시 비교 결과입니다. `modified_preserved`는 줄바꿈 차이와 기존 수정도 포함하므로 손상 판정 목록이 아닙니다.

복구 전 소스·설정·저장 데이터 스냅샷은 `backups/20261105-092915/`에 있습니다. SQLite는 연결 중인 경우에도 일관된 사본을 얻는 백업 API로 복사했습니다. 이 폴더에는 개인 계정 정보가 포함될 수 있으므로 Git 추적에서 제외했습니다. 원본 이미지 파일은 변경하지 않아 스냅샷 ZIP에 중복 포함하지 않았습니다.

## 재실행

프로젝트 루트의 PowerShell에서:

```powershell
python .\드림월드-복구도구\restore.py
python .\드림월드-복구도구\restore.py --verify-hashes
python .\드림월드-복구도구\restore.py --restore
```

첫 명령은 누락 목록 검사, 두 번째는 해시 검사, 세 번째는 스냅샷 후 **없는 파일만** 복구합니다. 기존 파일·저장 데이터·사용자 수정본을 덮어쓰거나 삭제하지 않습니다. 공개 저장소 조회에는 인터넷이 필요합니다. 해시 비교는 많은 파일을 읽으므로 시간이 걸릴 수 있습니다.

## 실행과 점검

각 드림월드 폴더에서 `.\start-server.ps1`을 실행합니다. 두 서버는 동일한 포트를 쓰므로 **두 폴더를 동시에 실행하지 마세요**. 게임싱크 등록 후 포켓몬을 재워야 원본 게임에 입장할 수 있습니다.

추가 구현본 웹 안내: http://127.0.0.1:8080/local/

추가 구현본의 `audit_reports/복구점검-2026-11-05.md`에 상세 수정·검증·미복구 원본 목록을 정리했습니다. 원본이 없는 그림의 재구성 안내는 원본 이미지 복구와 다릅니다. Flash 원본 UI 및 DS 실기 수령 검증도 별도로 필요합니다.
