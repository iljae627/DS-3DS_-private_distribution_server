# 드림월드 두 폴더 복구 검사 및 웹 개선 (2026-11-05)

## 결론

두 기존 폴더 `드림월드`, `드림월드-미완성부분구현`을 보존하고 검사했습니다. 밑줄 이름의 별도 복사본은 만들지 않았습니다. 현재 경로에는 공개 기준본의 코드 125개, 자료 10,464개, 게임싱크 코드 97개가 두 폴더 모두 존재합니다. 누락 파일이 없어 이번에 원본 파일을 새로 복사한 수는 0개입니다.

파일 존재 여부뿐 아니라 Git 객체 해시도 대조했습니다. 두 폴더의 공개 원본 이미지·SWF에는 해시 차이가 없습니다. 텍스트의 줄바꿈 차이와 기존 수정 코드는 유지했습니다. 따라서 현재 확인한 그림 누락·빈 화면을 이번 이동으로 발생한 바이너리 손상이라고 단정할 근거는 없습니다.

이 결과는 **모든 옛 공식 서비스와 원본 자료가 완전히 복구되었다는 뜻이 아닙니다**. 공개 보관본에 처음부터 없는 그림과 임시 파일이 존재합니다. 백업이 없다는 사용자 답변에 따라 공개 자료와 명시적인 로컬 재구성 안내를 기준으로 작업했습니다.

## 보존과 재복구

- 복구 전 소스·설정·저장 DB·WFC 자료 스냅샷: `../../드림월드-복구도구/backups/20261105-092915/`.
- SQLite 백업 API로 일관된 DB 사본을 만들었습니다. 원본 DSV/ROM 세이브는 수정하지 않았습니다.
- `../../드림월드-복구도구/restoration.json`: 누락 검사 및 스냅샷 경로.
- `../../드림월드-복구도구/integrity.json`: 원본과 해시가 다른 텍스트 등의 목록. 이 목록은 수정·줄바꿈 차이를 포함하며 손상 판정 목록이 아닙니다.
- `../../드림월드-복구도구/restore.py`: Git 이력과 공개 원본에서 없는 파일만 복구하는 도구. 기존 파일을 덮어쓰거나 저장 데이터를 지우지 않습니다.
- 기준본의 테스트도 임시 DB를 사용하도록 변경했습니다. 실제 사용 DB에 테스트 계정을 삽입하던 기존 테스트 방식을 제거했습니다.

## 검증 결과

- [재귀 점검 원자료](recursive-links.json): 페이지 경로 **835개**, 연결 리소스 **883개**, HTTP 오류 응답 **0개**.
- 자료실의 원본 이미지 **5,170개**에 대해 각각 상세 페이지와 원본 이미지 응답을 전수 검사했습니다. 목록 **130페이지**도 확인했으며 실패는 **0개**입니다. 전체 픽셀의 시각적 품질을 사람이 검수했다는 의미는 아닙니다.
- 같은 페이지의 `/`, `/index.html` 및 별칭 경로는 각각 셉니다. 서로 다른 원본 문서 835개라는 의미는 아닙니다.
- 기준본 테스트 **1개 통과**, 추가 구현본 테스트 **8개 통과**. 실제 테스트는 임시 DB에서 실행했습니다.
- 회귀 범위: 기존 꿈섬·친구보드·아이템·텃밭·DLC 전송 예약, 실제 Flash 요청 계약, 이미지 자료실의 목록→상세→원본 응답, 안내 SVG, 하위 링크, 잘못된 입력, 초기 FAQ 인코딩.
- Python 컴파일 검사 통과.
- Chrome에서 원본 이미지 자료실의 목록→상세 페이지 이동 및 이미지 표시를 실제 확인했습니다. [실제 상세 화면](image-detail-2026-11-05.png).
- 누락 그림의 안내 링크를 눌러 단계별 수령 안내로 이동하고, 원본이 아닌 재구성임을 표시한 설명도까지 확인했습니다. [실제 안내 화면](local-guide-2026-11-05.png).

HTTP 200만으로 그림·기능 복구를 주장하지 않기 위해 다음 항목을 따로 보고합니다.

- 누락 원본 이미지 **271개 고유 경로**, 문서 내 표기 **808회**. 해당 위치에는 원본 미보관을 표시하고 로컬 안내를 연결했습니다.
- 점검 중 만난 임시 파일 또는 100바이트 이하 이미지 **178개 요청 경로**. 작은 파일에는 정상 간격용 이미지도 포함될 수 있으므로 전부 손상으로 판정하지 않습니다. HTML 임시 파일은 안내 페이지로 보완했지만 원본 본문 복구는 아닙니다.
- 전체 자료 트리의 `AUTO-GENERATED PGL STUB` 텍스트 파일은 397개, 100바이트 이하 이미지는 365개였습니다. 현재 연결 범위 밖 파일도 포함한 재고 수치입니다.
- `#/...` 형태의 클라이언트 라우트 참조 44회는 단순 HTML 앵커 오류와 분리했습니다. 모든 라우트를 브라우저에서 조작 완료했다는 의미가 아닙니다.
- 외부 링크 참조 5,729회는 수집만 했으며 외부 공식 서비스의 작동을 보장하지 않습니다.
- 원본 Flash 게임 전체 조작과 DS/3DS 실기 수령은 이번에 검증하지 않았습니다.

추가 구현본 폴더에서 재현:

```powershell
.\.venv\Scripts\python.exe tools\audit_links.py --all-images
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

기준본 테스트는 `드림월드` 폴더에서 동일한 unittest 명령을 실행합니다. 재귀 검사와 테스트는 임시 저장 DB를 사용하며, 실제 사용 데이터를 테스트 데이터로 덮어쓰지 않습니다.
