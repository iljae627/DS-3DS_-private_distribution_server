# 5세대 PK5 → PGF 배포파일 변환기

PKHeX에서 내보낸 5세대 포켓몬 파일(`.pk5`)을 블랙·화이트·블랙2·화이트2의 이상한 소포용 204바이트 Wonder Card(`.pgf`)로 변환한다.

> PK5는 이름 그대로 **5세대** 포켓몬 파일이다. 4세대 `.pk4`는 이 도구가 아니라 `..\4세대-배포파일-변환기`를 사용한다.

## 현재 상태

- 136바이트 박스 PK5와 220바이트 파티 PK5 지원
- PK5 종 번호와 체크섬 검사
- 204바이트 PGF 생성 후 선물 유형·종 번호·카드 ID 재검증
- SHA-256 기반의 재현 가능한 기본 카드 ID
- 내장 자체 테스트 제공

## 사용법

1. PKHeX에서 배포할 포켓몬을 `.pk5`로 내보낸다.
2. PK5 파일을 `PK5를 PGF로 변환.cmd` 위로 끌어다 놓는다.
3. 같은 폴더에 만들어진 `.pgf`를 `..\5세대-배포서버\배포파일\`에 복사한다.
4. 5세대 배포 서버를 다시 시작한다.

변환기는 다음을 검사한다.

- 입력 크기: 박스 PK5 136바이트 또는 파티 PK5 220바이트
- 종 번호: 1~649
- PK5 내부 체크섬
- 출력 크기: 정확히 204바이트
- 출력 PGF의 선물 형식, 종 번호, 카드 ID

현재 폴더에는 실행에 필요한 컴파일 결과와 `PKHeX.Core.dll`이 포함되어 있다. Windows에 .NET 10 Runtime이 설치되어 있어야 한다.

## 명령줄 옵션

```powershell
dotnet ".\Gen5Converter.dll" "C:\PK5\피카츄.pk5" `
  --output "C:\PGF\피카츄.pgf" `
  --title "특별한 피카츄 선물" `
  --card-id 12001
```

| 옵션 | 설명 | 기본값 |
|---|---|---|
| `-o PATH`, `--output PATH` | 출력 PGF 경로 | 입력과 같은 경로·이름 |
| `--title TEXT` | 원더카드 제목 | `<닉네임> 선물` |
| `--card-id 1-2047` | 5세대 카드 ID | PK5 SHA-256에서 안정적으로 생성 |
| `--card-location 0-255` | 원더카드 출처 문구 인덱스 | `68`(포켓몬 플레이 감사 문구) |
| `--repeatable` | 반복형 특수 카드 상태 사용 | 사용 안 함(기본은 신규 수령 가능 상태) |
| `--keep-origin-game` | 원본 PK5의 게임 버전만 허용 | 모든 5세대 게임 허용 |
| `--self-test` | 내장 PK5 생성·변환·PGF 재검증 | - |

서로 다른 배포에는 겹치지 않는 `--card-id`를 지정하는 것이 좋다. 5세대 수신 기록이 사용하는 유효 범위는 1~2047이며, 같은 카드 ID의 수신 기록이 세이브에 있으면 다시 받지 못할 수 있다.

## 변환되는 정보와 한계

PGF는 포켓몬 개체의 복사본이 아니라 **수령할 포켓몬을 생성하는 선물 템플릿**이다. 종, 폼, PID, 트레이너 ID/이름, 성격, 성별, 특성 슬롯, 개체값, 기술, 지닌 도구, 볼, 리본, 만남 장소, 언어와 이로치 여부를 옮긴다. 현재 레벨을 수령 레벨로 사용한다. 수령 날짜는 5세대 배포 규격에 따라 비워 두며 게임이 실제 수령일을 기록한다.

PGF 형식에 저장 공간이 없는 경험치, 노력치, 친밀도, 포켓러스, 마킹, 배틀 상태, 현재 HP 등은 옮길 수 없다. 따라서 수령 결과가 원본 PK5와 바이트 단위로 같지는 않다. 생성물은 개인 테스트용이며 PKHeX 적법성 검사를 대신하지 않는다.

`--repeatable`은 일반적인 Wi-Fi 배포가 아닌 특수 카드용 고급 옵션이다. 게임과 세이브의 카드 ID 수신 기록 때문에 실제 반복 수신이 제한될 수 있다.

## 자체 테스트와 빌드

```powershell
dotnet ".\Gen5Converter.dll" --self-test
dotnet build ".\5세대-배포파일-변환기.csproj" -c Release
```

소스 빌드에는 .NET 10 SDK와 NuGet 복원 연결이 필요하다. 일반 실행에는 SDK가 아니라 .NET 10 Runtime만 필요하다.

전체 서버 실행 순서는 [프로젝트 README](../README.md)를 참고한다.
