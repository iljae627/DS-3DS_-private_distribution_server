# 포켓몬 4세대 개인 배포 서버

Windows PC에서 DNS, DS 호환 HTTPS, Wonder Card 배포를 모두 처리한다. 닌텐도 DS에서는 PC 핫스팟에 접속하고 DNS만 PC 주소로 지정하면 된다.

## 필요한 것

- Windows 10/11 PC
- PC의 인터넷 연결
- 2.4 GHz 무선 핫스팟
- 포켓몬스터 4세대 정품 카트리지
- 856바이트 `.pcd` Wonder Card

## 1. PC 핫스팟 준비

1. PC를 집 공유기나 휴대폰 핫스팟에 연결한다.
2. Windows에서 모바일 핫스팟을 켜고 네트워크 대역을 `2.4 GHz`로 설정한다.
3. `제어판 -> 네트워크 및 인터넷 -> 네트워크 및 공유 센터 -> 어댑터 설정 변경`을 연다.
4. DS에 공유할 핫스팟/무선 연결의 `무선 속성 -> 보안`에서 보안 종류를 `없음`, `Open` 또는 `인증 안 함`으로 설정한다.
5. DS가 이 무암호 핫스팟을 검색해 접속할 수 있는지 확인한다.

4세대 DS 게임은 최신 WPA2/WPA3 핫스팟에 접속하지 못하므로 핫스팟의 **Wi-Fi 암호화만** 끄는 설정이다. Windows Defender 방화벽을 전체로 끄지 않아도 된다. 시작 스크립트가 TCP 80/443 인바운드 규칙을 자동으로 만든다.

> Windows 기본 모바일 핫스팟에서 `없음/Open`을 제공하지 않는 PC는 무암호 핫스팟을 생성할 수 있는 무선 어댑터나 별도 AP가 필요하다.

## 2. PCD 배포 파일 추가

배포할 `.pcd` 파일을 다음 폴더에 넣는다.

```text
4세대-배포\배포 목록\
```

예:

```text
4세대-배포\배포 목록\피카추.pcd
4세대-배포\배포 목록\지라치.pcd
```

- PCD는 반드시 856바이트여야 한다.
- 하위 폴더는 검색하지 않는다.
- 여러 장이면 DS가 소포 목록을 요청할 때 하나를 무작위로 선택한다.
- 파일을 추가·삭제한 뒤에는 서버를 다시 시작한다.

## 3. 서버 실행

1. `4세대-배포` 폴더에서 **관리자 권한 PowerShell**을 연다.
2. 다음을 실행한다.

```powershell
cd "C:\Users\iljae\OneDrive\바탕 화면\DS-3DS_-private_distribution_server\4세대-배포"
Set-ExecutionPolicy -Scope Process Bypass
.\start-server.ps1
```

실행 정책 질문이 나오면 `A`를 입력한다. 다음이 나오면 서버가 준비된 것이다.

```text
[BOOT-HTTP] listening=192.168.137.1:80
[BOOT-HTTPS] listening=192.168.137.1:443
[SELFTEST-DNS-PASS] WinDivert driver opened
```

종료는 PowerShell에서 `Ctrl+C`를 누른다.

## 4. DS 연결

1. 게임 내 `Nintendo Wi-Fi Connection 설정`을 연다.
2. PC에서 만든 2.4 GHz 무암호 핫스팟을 선택한다.
3. `IP 주소 자동 취득`: `예`
4. `DNS 자동 취득`: `아니오`
5. `기본 DNS`: `192.168.137.1`
6. `보조 DNS`: `192.168.137.1`
7. 연결 테스트 후 `이상한 소포 -> 소포를 받는다 -> Nintendo WFC로 받는다`를 선택한다.

PC 핫스팟 주소가 `192.168.137.1`이 아닌 환경은 시작 로그에 표시된 `DS 기본/보조 DNS`를 사용한다.

## PK4 -> PCD 변환기

`\배포파일 변환기`는 현재 **제작 중**이다. 아직 실제 배포용 파일 제작에 사용하지 않는다.
