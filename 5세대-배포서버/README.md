# 포켓몬 5세대 사설 배포 서버

`배포파일` 폴더의 204바이트 `.pgf` 또는 720바이트 `.wc5full` 파일을 읽어 포켓몬 블랙·화이트·블랙2·화이트2의 `이상한 소포 -> Nintendo WFC로 받기`에 배포한다.

## 현재 상태

- PGF·WC5FULL 크기와 카드 정보 검사
- PGF를 720바이트 전송 구조로 포장
- 언어·게임 수신 조건에 맞는 카드 선택
- CRC16-CCITT 검증과 자동 테스트 구현
- 실제 네트워크 환경과 게임 조합별 수령 검증은 계속 진행 중

## 배포 파일

`배포파일` 폴더 바로 아래에 PGF 또는 WC5FULL을 넣는다. 서버는 시작할 때 크기, 카드 ID, 카드 상태와 WC5FULL 체크섬을 검사한다. 여러 파일이 있으면 요청마다 호환되는 카드 하나를 무작위로 고른다. 파일 변경 후에는 서버를 다시 시작해야 한다.

현재 PGF는 한국어 및 5세대 전 게임 수신 가능 카드로 포장된다. 원본 PGF 내용과 카드 자체의 제한은 변경하지 않는다.

## 실행

4세대 서버와 같은 Windows 핫스팟, Python 환경, DS용 인증서를 공유한다. 따라서 먼저 `4세대-배포` 서버의 최초 준비가 완료되어 있어야 한다.

1. Windows에서 DS가 접속할 수 있는 2.4GHz 핫스팟을 켠다.
2. 이 폴더에서 관리자 PowerShell을 연다.
3. 다음을 실행한다.

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\start-server.ps1
```

4. DS의 기본 DNS와 보조 DNS를 모두 화면에 표시된 핫스팟 주소(기본 `192.168.137.1`)로 설정한다.
5. 게임의 `이상한 소포 -> 소포를 받는다 -> Nintendo WFC로 받는다`를 선택한다.

다른 핫스팟 주소는 `./start-server.ps1 -HotspotIp 주소`로 지정한다. 종료는 `Ctrl+C`이다. 전체 로그는 `diagnostics.log`에 남는다.

문서의 기본 주소를 그대로 사용하지 말고 시작 화면에 표시된 `DS 기본/보조 DNS` 주소를 입력한다.

## 배포 흐름

```text
PGF 또는 WC5FULL 로드와 검사
→ 게임·언어 조건에 맞는 카드 선택
→ 720바이트 전송 데이터 준비
→ DLS count/list/contents 응답
→ 게임에서 Wonder Card 수령
```

## 자동 테스트

```powershell
..\4세대-배포\.venv\Scripts\python.exe -m unittest -v test_server.py
```

5세대 DLS 전송 데이터는 720바이트 WC5FULL 구조이며, 원본 PGF(204바이트), 게임 수신 플래그, 안내문, 언어 플래그, CRC16-CCITT를 포함한다.

## 문제 해결

- 서버 시작 실패: `4세대-배포`의 `.venv`와 인증서 준비가 완료됐는지 확인한다.
- 파일 오류: `배포파일` 바로 아래 PGF가 204바이트, WC5FULL이 720바이트인지 확인한다.
- 카드를 찾지 못함: 게임·언어 조건에 맞는 파일이 있는지 확인하고 서버를 재시작한다.
- DNS 로그만 있음: 인터넷 연결과 외부 WFC 인증 경로를 확인한다.
- 같은 선물을 다시 받지 못함: Wonder Card와 카드 ID 수령 기록을 확인한다.

전체 실행 순서는 [프로젝트 README](../README.md)를 참고한다.
