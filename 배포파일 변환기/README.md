# 4세대 PK4 → PCD 배포파일 변환기

PKHeX에서 내보낸 4세대 포켓몬 파일(`.pk4`)을 Nintendo DS 4세대 이상한 소포에서 사용할 수 있는 Wonder Card 파일(`.pcd`)로 변환하는 Windows용 도구이다.

생성된 PCD는 이 저장소의 개인 배포 서버에서 실제 배포 및 수신이 확인되었다. 다만 모든 포켓몬·언어·게임 조합을 보장하는 것은 아니므로 원본과 세이브 파일을 백업한 뒤 사용한다.

## 지원 범위

- 입력: 136바이트(박스) 또는 236바이트(파티) 4세대 `.pk4` 파일 1개
- 출력: 856바이트 `.pcd` Wonder Card
- 대상: 디아루가, 펄기아, 플라티나, 하트골드, 소울실버(기본값은 전체)
- 알 PK4: 알 선물 형식으로 자동 생성
- 실행 환경: 64비트 Windows 10/11

이 도구는 PK4의 포켓몬 데이터를 PCD 선물 영역에 넣는다. 포켓몬의 적법성, 이벤트 정당성, 게임별 수신 가능 여부를 보정하거나 보장하지는 않는다.

## 가장 간단한 사용법

1. PKHeX에서 배포할 포켓몬을 `.pk4`로 내보낸다.
2. `.pk4` 파일을 `PK4를 PCD로 변환.cmd` 위로 끌어다 놓는다.
3. 같은 폴더에 같은 이름의 `.pcd`가 생성되는지 확인한다.
4. 생성된 PCD를 `..\4세대-배포\배포 목록\`에 복사한다.
5. 배포 서버를 다시 시작하고 DS에서 이상한 소포를 수신한다.

예를 들어 `피카추.pk4`를 끌어다 놓으면 기본적으로 `피카추.pcd`가 생성된다. CMD 파일을 먼저 더블 클릭한 뒤 열린 창에 PK4를 끌어다 놓고 Enter를 눌러도 된다.

> **주의:** 출력 위치에 같은 이름의 PCD가 있으면 확인 없이 덮어쓴다. 필요한 기존 파일은 먼저 백업한다.

## 정상 변환 결과

```text
변환 완료
입력 : C:\...\피카추.pk4
출력 : C:\...\피카추.pcd
포켓몬: 피카추 (종 번호 25)
카드 ID: 12345
제목 : A special 피카추!
크기 : 856바이트
```

프로그램은 변환 전에 PK4 크기, 종 번호와 체크섬을 검사한다. 저장 후에는 PCD를 다시 읽어 크기와 포켓몬 종이 일치하는지도 검사한다. 오류가 표시되면 생성물을 사용하지 않는다.

## 명령줄 사용법

```powershell
cd "C:\경로\DS-3DS_-private_distribution_server\배포파일 변환기"
& ".\배포파일 변환기.exe" "C:\PK4\피카추.pk4"
```

옵션 사용 예:

```powershell
& ".\배포파일 변환기.exe" `
  "C:\PK4\피카추.pk4" `
  --output "C:\PCD\특별한 피카추.pcd" `
  --title "특별한 피카추 선물!" `
  --description "이상한 소포로 온 특별한 포켓몬입니다." `
  --card-id 12001 `
  --games d,p,pt,hg,ss `
  --redistribution 0
```

| 옵션 | 설명 | 기본값 |
|---|---|---|
| `-o PATH`, `--output PATH` | 출력 PCD 경로 | 입력과 같은 폴더/이름 |
| `--title TEXT` | 원더카드 제목 | `A special <닉네임>!` |
| `--description TEXT` | 원더카드 설명 | 영문 기본 문구 |
| `--card-id NUMBER` | 1~65535 카드 ID | PK4 내용에서 자동 생성 |
| `--games LIST` | 수신 가능한 게임 | `all` |
| `--redistribution NUMBER` | 재배포 설정 바이트(0~255) | `0` |
| `--gift-instance NUMBER` | 선물 인스턴스 값(고급) | `1` |
| `-h`, `--help` | 도움말 표시 | - |

`--games` 값:

| 게임 | 입력값 |
|---|---|
| 디아루가 | `d` 또는 `diamond` |
| 펄기아 | `p` 또는 `pearl` |
| 플라티나 | `pt` 또는 `platinum` |
| 하트골드 | `hg` 또는 `heartgold` |
| 소울실버 | `ss` 또는 `soulsilver` |
| 전체 | `all` |

여러 게임은 `d,p,pt`처럼 쉼표로 연결한다. `--help`로 프로그램 자체 도움말도 볼 수 있다.

## 기본값과 카드 ID

옵션을 생략하면 출력 경로는 입력 PK4의 확장자만 `.pcd`로 바꾸고 제목과 설명에는 영문 기본 문구를 쓴다. 카드 ID는 PK4 데이터의 SHA-256 값을 이용해 1~65535 범위에서 자동 결정하므로 같은 PK4는 항상 같은 ID가 된다.

DS 세이브의 Wonder Card 또는 수신 기록과 카드 ID가 충돌하면 선물을 받지 못할 수 있다. 서로 다른 배포에는 고유한 `--card-id`를 지정하고 사용한 번호를 기록해 두는 것을 권장한다.

## 서버에 넣기

PCD를 `..\4세대-배포\배포 목록\` 바로 아래에 넣는다.

- 파일 크기는 정확히 856바이트여야 한다.
- 파일을 추가·교체·삭제한 뒤에는 서버를 다시 시작한다.
- 하위 폴더의 PCD는 읽지 않는다.
- PCD가 여러 개면 서버가 요청마다 하나를 무작위로 선택한다.
- 서버 실행과 DS DNS 설정은 저장소 최상위 `README.md`를 따른다.

## 주의사항

1. **원본과 세이브를 백업한다.** 변환기는 PK4를 수정하지 않지만 실기 수신 전 DS 세이브 백업을 권장한다.
2. **PKHeX 적법성 검사를 대신하지 않는다.** 기술, 만남 정보, 리본, 언어·지역 조합이 부자연스러워도 형식만 맞으면 변환될 수 있다.
3. **문자 호환성을 확인한다.** 게임 언어에서 지원하지 않는 문자나 긴 제목·설명은 깨지거나 잘릴 수 있다. 같은 언어의 짧은 문구를 쓰고 실기에서 시험한다.
4. **카드 ID를 관리한다.** 여러 이벤트에는 서로 다른 ID를 쓰고 기록해 둔다.
5. **고급 옵션은 기본값을 권장한다.** `--gift-instance`와 `--redistribution`은 의미를 아는 경우에만 변경한다.
6. **공식 배포로 오인하지 않게 관리한다.** 개인 제작 PCD이므로 파일명이나 설명에 출처를 남긴다.

## 오류 해결

### `PK4 파일을 찾을 수 없습니다`

파일을 CMD 창에 직접 끌어다 놓거나 전체 경로를 큰따옴표로 감싼다.

### `PK4 크기는 136 또는 236바이트여야 합니다`

4세대 PK4가 아니거나 다른 형식으로 저장된 파일이다. PKHeX에서 다시 `.pk4`로 내보낸다. `.pk3`, `.pk5`, 세이브 또는 PCD는 입력할 수 없다.

### `PK4 체크섬이 올바르지 않습니다`

파일이 손상되었거나 정상 PK4 구조가 아니다. PKHeX에서 열어 확인한 뒤 다시 내보낸다.

### `유효한 4세대 포켓몬 종 번호가 아닙니다`

빈 슬롯, 손상 파일 또는 4세대 범위를 벗어난 데이터다. 1~493번 포켓몬의 정상 PK4를 사용한다.

### DS에서 선물을 찾지 못하거나 받지 못함

1. PCD가 `4세대-배포\배포 목록\` 바로 아래에 있는지 확인한다.
2. 크기가 856바이트인지 확인하고 서버를 재시작한다.
3. `--games`에 현재 카트리지 버전이 포함됐는지 확인한다.
4. 같은 카드 ID를 이미 받은 기록이나 카드가 세이브에 남아 있는지 확인한다.
5. 기존 검증 완료 PCD로 수신해 변환 파일 문제인지 구분한다.

### 창이 바로 닫힘

EXE 대신 `PK4를 PCD로 변환.cmd`를 사용하거나 PowerShell에서 EXE를 실행한다.

## 직접 빌드하기

일반 사용자는 포함된 EXE를 사용하면 된다. 소스에서 다시 빌드하려면 프로젝트가 지정한 .NET 10 SDK와 NuGet 복원용 인터넷 연결이 필요하다.

```powershell
dotnet restore ".\배포파일 변환기.csproj"
dotnet build ".\배포파일 변환기.csproj" -c Release
dotnet publish ".\배포파일 변환기.csproj" -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

변환 로직은 `Program.cs`에 있으며 PK4/PCD 처리를 위해 `PKHeX.Core`를 사용한다.
